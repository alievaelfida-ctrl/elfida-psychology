# Елфида Алиева — лендинг страница

Evergreen лендинг страница за индивидуална психологическа подкрепа онлайн на български.

## Записване

Страницата използва публичния Calendly адрес:

`https://calendly.com/alievaelfida/1h`

Calendly е свързан с Google Calendar и Zoom. Посетителят избира свободен час и получава потвърждение и Zoom информация по имейл.

## Поверителност и проследяване

Проследяват се само позволени UTM параметри и анонимни действия по страницата. Имена, имейли, здравна информация, текстове от съобщения и данни за срещи не се изпращат към аналитиката.

Имейл формата за бъдещата общност е неактивна, докато не бъде свързана с одобрена имейл услуга.

## Публикуване

Проектът е статичен и може да бъде публикуван директно във Vercel без build команда.
